📊 VOCABULARY SUMMARY

Core Terms:

AI (Artificial Intelligence)
  └─ Machines performing tasks that normally require human intelligence

ML (Machine Learning)
  └─ Machines learning patterns from data instead of being programmed

DL (Deep Learning)
  └─ ML using neural networks with many layers

LLM (Large Language Model)
  └─ AI trained on massive text to predict next words

Transformer
  └─ Architecture using attention mechanism

Attention Mechanism
  └─ Focus on important parts of input

Token
  └─ Word or part of word (LLMs work with tokens)

Embedding
  └─ Vector (list of numbers) representing text/data

Vector DB
  └─ Database optimized for similarity search using embeddings

RAG (Retrieval-Augmented Generation)
  └─ Retrieve documents then generate answers from them

Agent
  └─ AI system that takes actions autonomously

Hallucination
  └─ When AI confidently states false information

Fine-tuning
  └─ Training a pre-trained model on new data

RLHF (Reinforcement Learning From Human Feedback)
  └─ Training using human preferences and ratings

Prompt
  └─ Instructions/input you give to an AI model

Prompt Engineering
  └─ Art of writing effective prompts

Context Window
  └─ Amount of previous text model can see

Parameters
  └─ Numbers that neural network learns

Weights & Bias
  └─ Parameters that neural network adjusts

Loss Function
  └─ Measures how wrong the model's prediction is

Gradient
  └─ Direction to adjust weights to reduce loss

Backpropagation
  └─ Process of calculating gradients

Activation Function
  └─ Non-linear function applied to neuron output

🧠 KEY INSIGHTS TO REMEMBER

1. AI = Pattern Recognition at Scale
   └─ Neural networks recognize patterns in data
   └─ More data + more parameters = better patterns

2. Training is Iterative
   └─ Start random, gradually improve
   └─ Backprop calculates right direction to improve
   └─ Millions of tiny improvements = learning

3. Attention is the Secret Sauce
   └─ Knowing what to focus on is powerful
   └─ Attention mechanism lets models focus selectively
   └─ Multi-head attention looks at different aspects

4. Transformers Changed Everything
   └─ Parallel processing (efficient)
   └─ Long context (can remember lots)
   └─ Powers modern AI

5. LLMs Predict Next Word
   └─ That's literally what they do
   └─ Patterns learned ≠ Understanding
   └─ Yet surprisingly capable

6. Size Matters (But Not Everything)
   └─ More parameters → more capability
   └─ But also more cost and slowness
   └─ Right-sizing is important

7. RAG Solves Knowledge Problem
   └─ LLMs have knowledge cutoff
   └─ RAG lets them access current info
   └─ Reduces hallucinations

8. Agents Add Autonomy
   └─ LLMs + Tools + Reasoning = Agents
   └─ Can solve multi-step problems
   └─ More powerful but need careful design

9. Everything is Probabilistic
   └─ AI doesn't "know" things for sure
   └─ Makes best guesses based on patterns
   └─ Sometimes gets it wrong

10. Responsible AI is Critical
    └─ Power requires responsibility
    └─ Bias, privacy, safety matter
    └─ Always think about impact
